# Campus event readiness checklist

Use this checklist before publishing or operating a campus event.

## Event setup

- [ ] Confirm organizer identity and authority to publish the event.
- [ ] Verify title, venue, date, start/end times, and capacity.
- [ ] Confirm registration rules and whether attendee information is visible to organizers.
- [ ] Include accessibility and contact information where available.

## Before the event

- [ ] Assign an event owner and a backup contact.
- [ ] Confirm venue permission and any institutional approval.
- [ ] Communicate cancellations or schedule changes through the official channel.
- [ ] Limit attendee exports to staff who need them.

## After the event

- [ ] Close registration when appropriate.
- [ ] Record attendance using the approved process.
- [ ] Remove temporary organizer access.
- [ ] Retain or delete attendee data according to the stated purpose and policy.
